# Code of Conduct

## Our pledge

We want participating in Neolink to be free of harassment for everyone,
regardless of experience level, hardware budget, employer, or identity.

## Expected behaviour

- Assume competence. A report that a dock doesn't work is data, not a complaint.
- Be concrete: model, macOS build, and what you actually saw.
- Accept that pre-1.0 things break, and that "unvalidated on hardware" is a
  real state and not a brush-off.
- Disagree about the code, not the person.

## Unacceptable behaviour

- Harassment, and dismissive "just read the source" answers to good-faith questions
- Derailing issues into unrelated platform or editor arguments
- Claiming code from Synaptics' binary as ours without citing the address

## Scope

Issues, pull requests and discussions in this repository.

## Enforcement

Report a problem to the maintainer at the address in `git log`, or open an
issue titled "CoC: ...". The maintainer's decision on a report is final, and
may range from a note to a block on the repository.
